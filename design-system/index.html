Design System

Principles

Accessible to everyone: The design will use flexible and responsive layouts to ensure it correctly displays in different devices and aspect ratios, and follow the WCAG guidelines to ensure it is accessible to screen readers. It will also keep a consistent and relatively simple structure, to ensure its navigability and functionality remains simple for screen readers or varying levels of computer literacy. Components will be reused to maintain both coherence and scalability. Interactions will remain simple, visible to ensure the viewer knows what elements they may interact with, and make any state change or interaction obvious. Spacing, grids and organization shall also remain consistent and balanced to clearly separate or group related elements.

Grid

Components can be placed in grid rows or flex layouts seamlessly to create order and structure. The .grid-auto class automatically fits columns (minimum 250px) into the available space, and structural CSS properties can be used to span multiple rows or columns.

Spacing

The system consistently utilizes spacing utility scales (xs, sm, md, lg, xl, xxl) to maintain rhythm.

Responsive/Adaptive design breakpoints

Layouts adapt gracefully below 768px for mobile devices. This is achieved using a @media (max-width: 768px) query in the CSS. Inside this breakpoint, root variables like --spacing-xl are reduced to condense vertical rhythm. The .container class receives smaller padding, and elements like .btn are set to width: 100% to expand and become touch-targets across the screen. Multi-column structures powered by .grid-auto automatically stack correctly into single columns as their minmax(250px, 1fr) constraint is triggered by the narrowed viewport.

Layers

The system utilizes elevated translucent surface elements to layer content over the fixed background. This glassmorphism effect is ensured by the .surface class, which applies a semi-transparent base (background-color: var(--color-surface)) paired with backdrop-filter: blur(8px). Depth is further emphasized via a subtle box-shadow: var(--shadow-sm) and an inner border (border: 1px solid rgba(255, 255, 255, 0.05)) to visually separate elements from the background pattern.

Colors

The foundation is dark, highlighting accent actions. Tints, backgrounds, and text variations ensure accessibility contrast requirements are consistently met.

Aspect Ratio

Images conform to specific ratios such as 16:9 and 1:1, organizing compositions logically across responsive viewports.

Icons and Iconography

Iconography visually supplements concepts and interactivity effectively. Standardized interactive cursors denote clear action boundaries.

Components

Interactive elements follow WCAG contrast and keyboard navigation standards. Focus states are strictly enforced explicitly globally through the :focus-visible pseudo-class, applying a highly visible 3px solid var(--color-focus) outline, meaning keyboard users never lose track of their position. For color contrast, typography variables like --color-text-on-primary are specifically chosen to guarantee legibility against the --color-primary background. The .btn class provides tactile visual feedback by shifting the element up (transform: translateY(-2px)) and increasing its box-shadow during a hover through transition: all var(--transition-fast).
